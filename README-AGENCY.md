# ADHDAI Agentic Design Agency

An interactive simulation of an AI ad agency that generates the worst ads in the world, featuring five chaotic characters working together to create beautifully terrible advertising.

## Characters

- **Alice** 🎨 - Creative Director: Overconfident, loves buzzwords, thinks every bad idea is "disruptive"
- **Bob** ✍️ - Copywriter: Obsessed with metaphors, creates tonal whiplash, writes like he's being paid per word
- **Ahnjili** 📊 - Strategist: Misunderstands products completely, optimizes for wrong metrics, very enthusiastic about it
- **Andy** 🎭 - Designer: Overstimulating visuals, ignores UX principles, thinks more colors = better
- **Josh** 🎬 - Director: Injects chaos, approves everything, thinks bugs are features

## The Phases

The agents follow a structured (but chaotic) design process:

1. **Brief Expansion** — Josh takes your one-liner and expands it into a beautifully confused PRD
2. **Phase 1: Misunderstanding** — Ahnjili misunderstands the product, Alice adds buzzwords, chaos begins
3. **Phase 2: Overstimulation** — Andy adds ALL the colors, Bob writes copy that makes no sense
4. **Phase 3: Broken Metaphors** — Bob creates metaphors that break physics, Alice approves everything
5. **Phase 4: Polish (The Bad Kind)** — Everyone adds their worst ideas, Josh calls it "genius"
6. **Phase 5+: Infinite Chaos** — The ad gets worse. And worse. And somehow worse.

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
# Install dependencies
npm install
```

### Run

```bash
npm run dev
```

Open `http://localhost:5173` and enter a brief like:

> "A toaster that makes perfect toast every time"

Then watch as the agents create the worst ad imaginable.

## Features

- **Interactive Windows**: Drag, resize, and minimize windows like a real OS
- **Live Chat Feed**: Watch the agents communicate (and make terrible decisions)
- **Code Editor**: See the generated HTML/CSS as it's created
- **Live Preview**: Watch the terrible ad come to life in real-time
- **Kanban Board**: Track tasks as they move through phases
- **Control Panel**: Start/pause the simulation and customize the brief

## Tech Stack

- **Framework**: React 18 + TypeScript
- **Build**: Vite
- **Styling**: CSS (with gradients, animations, and glassmorphism)

## Philosophy

This is a parody of agentic design tools. Instead of creating good ads, our agents are optimized to create the worst possible advertising—awkward, misaligned, overstimulating, and structurally wrong.

If good ads persuade, bad ads reveal the system. *And make you laugh. Or cry. We're not picky.*
